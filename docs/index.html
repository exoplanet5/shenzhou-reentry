Capsule status

Reconstruction vs reported

Reported times are to the minute (CMSA / CCTV). The model is solved to the reported landing point and minute for a burn ignition set by the reported orbital-module separation; the entry angle, loads and heating follow from it.

Element sets



The Space-Track set is the observed pre-burn orbit. The deorbit-ellipse set is the model state at burn cutoff (perigee below the surface; placeholder catalog number). A changed T0 shifts epoch and RAAN; the viewer plays numerical samples, not SGP4.
